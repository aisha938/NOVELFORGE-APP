# Novel Forge

A modern novel reading and publishing platform designed for readers and writers to discover, upload, and enjoy stories seamlessly.

---

## Overview

Novel Forge is a web-based platform that allows users to:

- Read novels online
- Upload and publish stories
- Interact with authors and readers
- Discover trending and recommended novels
- Enjoy a clean and immersive reading experience

The project focuses on combining a modern UI with smooth performance to create an engaging storytelling community.

---

## Features

### Reader Features
- Responsive reading interface
- Dark and light mode
- Bookmark chapters
- Reading history
- Continue reading section
- Search and discover novels
- Genre-based browsing
- Smooth chapter navigation

### Writer Features
- Upload and manage novels
- Chapter publishing system
- Edit stories anytime
- Cover image support
- Genre and tag organization

### Community Features
- Likes and ratings
- Comments and feedback
- Follow favorite authors
- Notifications for updates

### UI/UX
- Modern responsive design
- Mobile-friendly layout
- Smooth animations
- Clean typography
- Fast-loading pages

## Installation

1. Clone the repository:

```bash

```

2. Open the project folder:

```bash
cd novel-forge
```

3. Run the project:
- Open `index.html` in your browser
